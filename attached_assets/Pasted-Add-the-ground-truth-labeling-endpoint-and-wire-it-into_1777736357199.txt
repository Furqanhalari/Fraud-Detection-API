Add the ground-truth labeling endpoint and wire it into the backtest pipeline.

BACKEND (POST /api/v1/transactions/{transaction_id}/label):
- Requires X-API-Key header (same auth as all POST routes)
- Path param: transaction_id (the external string ID, not the UUID primary key)
- Input JSON:
  {
    "is_fraud": boolean,
    "label_source": "chargeback" | "investigation" | "manual" | "synthetic",
    "notes": string (optional, max 500 chars)
  }
- Logic:
  1. Look up transaction by transaction_id field (not id)
  2. Return 404 if not found: {"error": "not_found", "transaction_id": "..."}
  3. Update: is_fraud_actual = is_fraud
  4. Also add label_source and label_notes columns to transactions table
     (create Alembic migration for these two new columns)
  5. Log: logger.info(f"[label] {transaction_id} labeled as fraud={is_fraud} source={label_source}")
  6. Return the updated transaction row
- Output on success:
  {
    "transaction_id": string,
    "is_fraud_actual": boolean,
    "is_fraud_predicted": boolean,
    "fraud_score": float,
    "label_source": string,
    "was_correct": boolean,        ← is_fraud_actual == is_fraud_predicted
    "labeled_at": ISO timestamp
  }
- Output on error: {"error": "type", "message": "..."}

BACKEND (POST /api/v1/transactions/bulk-label):
- Same auth requirement
- Input JSON:
  {
    "labels": [
      {
        "transaction_id": string,
        "is_fraud": boolean,
        "label_source": "chargeback"|"investigation"|"manual"|"synthetic"
      }
    ]
  }
- Max 500 labels per request. Return 400 if exceeded.
- Logic: process each label, collect results, continue on individual failures
- Output:
  {
    "processed": number,
    "succeeded": number,
    "failed": number,
    "failures": [{"transaction_id": string, "reason": string}],
    "accuracy_snapshot": {
      "correct_predictions": number,
      "total_labeled": number,
      "accuracy": float
    }
  }

BACKEND (GET /api/v1/transactions/{transaction_id}):
- Returns single transaction row with all fields including is_fraud_actual if set
- Returns 404 if not found
- Use case: callers can check the current label before overwriting
